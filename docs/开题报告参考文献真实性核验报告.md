## 三、正文归因复核

正文引用文献时的主要归因与来源基本一致：

1. 教育部第43号令确实将辅导员定位为大学生日常思想政治教育和管理工作的组织者、实施者、指导者。
2. 第6—12条能够支持生成式人工智能对教育创新、教师工作变革、教学辅助能力及风险治理的论述。
3. “118个问题、800轮询问”来自第10条原文摘要，数字无误。
4. 第14条能够支持人工智能推动辅导员工作由经验驱动转向数据支持的概括。
5. 第16—19条能够支持本地知识库、RAG检索、重排序和证据约束问答的技术论述。
6. “现有研究对多角色业务闭环、资料权限隔离和留言转接关注不足”属于作者基于文献与系统需求作出的研究判断，不是某一篇文献的直接结论；在开题报告中作为问题归纳是可以接受的，但论文正文中应说明这是文献综合分析后的判断。
